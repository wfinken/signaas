Haiku
description: Five syllables, seven, five. No exceptions.
aliases: poem, poetry, 5-7-5

The inbox is full / but the cursor keeps blinking / patient as a stone
Autumn light, and still / three unanswered messages / wait beneath the fold
A meeting was moved / the calendar does not care / neither does the moon
Send button pressed once / the words are no longer mine / snow on the server
Rain on the window / I reply to everyone / except to myself
Quiet Monday mail / a thread that will not resolve / the kettle boiling
One draft, then a pause / the cursor learns to be still / send it anyway
Deadline like thunder / far off, then very close, then / only the echo
The server room hums / somewhere a message waits, cold / spring will come for it
No reply needed / the pond keeps the stone's secret / go well, and go now
Two hundred unread / a heron stands in the reeds / neither of us moves
This email is done / a leaf lets go of the branch / the afternoon holds
Old thread, new subject / the same question, wearing shoes / walk it out with me
Cold coffee, warm screen / the day writes itself in drafts / none of them are sent
Attachment attached / a small boat leaves the harbour / may it find the shore
The wind through the wires / your name at the end of it / that is the whole note
Signing off softly / the way a door closes when / the house is asleep
